# Aforia · demo

Demostración interactiva de simulación de multitudes: salida de una mascletà en la
plaza del Ayuntamiento de València, con cortes de calle, accidentes y distintos aforos.

Prototipo. Las cifras sirven para comparar escenarios, no como predicción exacta.
